# AI Resume Reviewer

A simple resume review application built using Streamlit and Google's Gemini API.

## Features

- Upload PDF or DOCX resume
- ATS Score
- Resume Summary
- Strengths
- Weaknesses
- Missing Skills
- Improvement Tips

## Tech Stack

- Python
- Streamlit
- Gemini API

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
